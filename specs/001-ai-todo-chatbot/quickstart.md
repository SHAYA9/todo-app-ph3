# Quickstart: AI Todo Chatbot

This guide provides a brief overview of how to get started with the AI Todo Chatbot.

## Backend

The backend is a Python application that hosts the AI agent.

1.  **Install dependencies**: `pip install -r requirements.txt`
2.  **Configure environment**: Set the required API keys for the OpenAI service in a `.env` file.
3.  **Run the application**: `python backend/src/agent/main.py`

## Frontend

The frontend is a web interface for interacting with the chatbot.

1.  **Install dependencies**: `npm install`
2.  **Run the application**: `npm start`
3.  Open your browser to `http://localhost:3000`.

## Usage

Once the application is running, you can interact with the chatbot using natural language. Try the following commands:

-   "Add a task to buy groceries"
-   "Show me my tasks"
-   "I finished the groceries task"
-   "Delete the groceries task"
